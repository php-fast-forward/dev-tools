Add opt-in `setup:skills` (`skills:setup`) to install LLM Skills as a consumer development dependency and configure sources through its official CLI. Preserve existing skills policies, register non-empty local skill payloads for DevTools itself, pin external DevTools skills to the executing source commit or an explicit ref, and add the Changelog source at `^0.4.0`. Support read-only previews and optional deferred synchronization.
