Project Agent Prompts
=====================

DevTools 2 removes ``agents`` and automatic links into ``.agents/agents``.
Custom role prompts remain repository-owned and distinct from procedural
skills installed through LLM Skills.

Inventory old links before removing the Composer dependency. Preserve custom
directories and edited files. Choose a real owner and supported distribution
contract before replacing links. LLM Skills does not synchronize arbitrary
role prompts, workflow files or repository metadata.

See :doc:`syncing-packaged-skills` and :doc:`dev-tools-2-migration`.
